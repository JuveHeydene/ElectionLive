# ElectionLive — front end

Next.js 15 application (in `frontend_sig/`): live map (Leaflet), charts (Recharts) and role-based dashboards.

```bash
cd frontend_sig
npm install
npm run dev      # http://localhost:3000 — expects the API on http://localhost:8000
```

See the [main README](../README.md#getting-started) for the full setup.
